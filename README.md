# 💼 Salary Predictor

A machine learning web application that estimates annual salary based on **education level, years of experience, job title, location, and age**.

Built with Python, scikit-learn, and Streamlit for a company project submission demonstrating a real-world ML use case.

---

## Project Structure

```
salary-predictor/
├── app.py              # Streamlit web application
├── train_model.py      # EDA, model training, evaluation & saving
├── generate_data.py    # Synthetic dataset generator (auto-called if needed)
├── requirements.txt    # Python dependencies
├── data/
│   └── salary_data.csv # Generated dataset (2,000+ records)
├── models/
│   ├── best_model.joblib              # Best pipeline (auto-selected)
│   ├── linear_regression_pipeline.joblib
│   ├── random_forest_pipeline.joblib
│   └── metadata.joblib               # Category lists + eval results
└── charts/             # EDA and residual charts (created on training)
```

---

## Dataset

A **synthetic dataset** of 2,000+ salary records is generated by `generate_data.py`.

| Column       | Type    | Description                                      |
|--------------|---------|--------------------------------------------------|
| `age`        | numeric | Employee age (18–65)                             |
| `education`  | category| High School / Associate / Bachelor / Master / PhD|
| `job_title`  | category| 12 common roles (Software Engineer, Data Scientist, etc.) |
| `location`   | category| 10 US cities with cost-of-living adjustments     |
| `experience` | numeric | Years of professional experience (0–30)          |
| `salary`     | numeric | Annual salary in USD (target variable)           |

The dataset intentionally includes ~2% missing values and ~1% duplicates to demonstrate cleaning steps.

## Quick Start

### 1. Clone / download the project

```bash
cd salary-predictor
```

### 2. Create and activate a virtual environment (recommended)

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Train the model

```bash
python train_model.py
```

This will:
- Auto-generate `data/salary_data.csv` if it does not exist
- Print EDA statistics and save charts to `charts/`
- Train Linear Regression and Random Forest models
- Print MAE, RMSE, and R² for both models
- Save the best model pipeline to `models/best_model.joblib`

### 5. Launch the web application

```bash
streamlit run app.py
```

Open your browser at **http://localhost:8501**

> The app auto-trains the model on first launch if `models/best_model.joblib` is missing.

## Machine Learning Pipeline

```
Raw CSV
  │
  ▼
Data Cleaning (drop duplicates, fill NaN with median, fix dtypes)
  │
  ▼
Feature Selection: age, education, job_title, location, experience
  │
  ├─ Numerical  → StandardScaler
  └─ Categorical → OrdinalEncoder
  │
  ▼
ColumnTransformer (preprocessor)
  │
  ├─ LinearRegression
  └─ RandomForestRegressor (n_estimators=200)
  │
  ▼
Evaluation: MAE, RMSE, R²  (80/20 train-test split)
  │
  ▼
Best model saved → models/best_model.joblib
```

## Model Evaluation

Results are printed during `train_model.py` execution.  
Typical results on the synthetic dataset:

| Model              | MAE ($)   | RMSE ($)  | R²     |
|--------------------|-----------|-----------|--------|
| Linear Regression  | ~5,800    | ~7,400    | ~0.93  |
| Random Forest      | ~3,200    | ~4,300    | ~0.97  |

> **Random Forest** is selected as the best model due to its higher R² and lower errors.  
> Actual values are printed when you run `train_model.py`.

## Key Observations from EDA

- **Education** has the strongest categorical impact on salary — a PhD earns ~$60k more than High School on average.
- **Experience** shows a strong positive linear correlation (r ≈ 0.70) with salary.
- **Location** creates a 30–45% premium for San Francisco vs Dallas.
- **Job Title** — Data Scientist and Product Manager are among the highest-paid; Sales Representative is lowest.

## Disclaimer

Predictions are **statistical estimates** based on synthetic training data. They do not represent actual salary guarantees, job offers, or professional HR advice. Real-world salaries depend on company, industry, negotiation, and many other factors.
